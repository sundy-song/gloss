Pricing Documentation

Why bilingual reading works better

Reading technical documentation in a second language is slow but valuable. A bilingual layout keeps the original sentence in place while placing a translation directly underneath, so you can check a term without losing your position in the text.

The extension only inserts new elements. It never rewrites the page, which means links, buttons, forms and selection still behave exactly as before.

Why terms and collocations matter

A collocation is a pair of words that native speakers habitually use together, such as make a decision or heavy rain. Learning the whole chunk is easier than learning each word alone, because the pattern transfers to new sentences.

Technical vocabulary behaves the same way. Once you recognise terms like working memory, accessibility tree or mutation observer, the original English becomes readable without a translation underneath.

What gets translated

  • Paragraphs, headings, list items and table cells.
  • Short interface labels such as buttons, tabs and menu entries.
  • Content that appears later, for example after scrolling or switching tabs.
Feature Behaviour Default
Display mode Show the translation below each paragraph, or replace the source text. Bilingual
Translation engine Chrome built-in model, Google endpoint, or your own API key. Automatic
Code blocks Left untouched on purpose, so snippets stay copyable. Skipped
